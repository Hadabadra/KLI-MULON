## איפה הכל
- ריפו: https://github.com/Hadabadra/KLI-MULON (ענף `main`).
- שחרור: כל דחיפה ל-`main` שמשנה את `version` ב-`manifest.json` מריצה את `.github/workflows/release.yml`, שבונה `milon-klei-kodesh-X.Y.Z.otzplugin` ומפרסם Release עם תג `vX.Y.Z` והערות מ-`CHANGELOG.md`. אפשר גם להריץ ידנית (Actions ← release ← Run workflow).
- תוכנית עבודה: `docs/ROADMAP.md` (מוטמעת בתוסף דרך `python tools/build_roadmap.py docs/ROADMAP.md data/roadmap.js`).
- בדיקת שורשים: `node tests/run-roots.js -v` (93.9% שורשים, 94% בניינים, על סט שנכתב ע"י AI).
- פוסט בפורום: https://otzaria.org/forum/post/45486 (הנוסח המעודכן ל-1.1.0 נמסר בשיחה; כרגע הנושא מסומן כמחוק בפורום).

- בדיקה בפועל באוצריא של 1.1.0 (הבדיקות נעשו בסימולציית דפדפן).
- רישיון מאגר כליקודש + קובץ LICENSE.
