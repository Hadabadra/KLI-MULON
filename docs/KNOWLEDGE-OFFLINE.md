# מצב "ללא גישה לאינטרנט" באוצריא — כלל לכל התוספים (02.11.2026)

- אוצריא מסתירה במצב מנותק כל תוסף שמצהיר על ההרשאה `network.access` (API_REFERENCE: תוסף "דורש רשת במצב מנותק" אינו זמין).
- תוסף **אינו יכול** לבטל לעצמו הרשאה בזמן ריצה, ואין במניפסט דגל "הרשאה אופציונלית".
- המשתמשת ביקשה: לא לשנות או להסיר הרשאות בתוספים בעקבות זה. השאלה נשארת פתוחה לבקשה מצוות אוצריא (שתוסף עם רשת יישאר זמין במצב מנותק, בלי הרשת).
- תוסף שצריך רק קישורים חיצוניים — `app.open_url` מספיק ואינו מסתיר אותו (כך לשון הקודש).
- בדיקת מצב: `app.getConnectivity()` → `isOfflineMode` / `isOnline`.
