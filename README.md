# מילון כליקודש — תוסף לאוצריא

מילון עברי בתוך אוצריא. מסמנים מילה בספר, והפירוש קופץ.

## יכולות
- **זיהוי אוטומטי בזמן לימוד:** הודעה קופצת עם ההסבר; לחיצה עליה פותחת את הערך. עובד עם ניקוד, תחיליות וסיומות, ועם בחירה של כמה מילים.
- **חיפוש תוך כדי הקלדה**, מילים דומות, ניווט אלפביתי ותצוגת אריחים של כל המילים עם סינון לפי אות.
- **שורשים ובניינים (הערכה אוטומטית):** מאומתים מול שורשי ספר השרשים לרד"ק שבמאגר. עלולים לטעות.
- **פירושים לפי הקשר:** כשיש כמה פירושים, נבחר לפי ניקוד והמילים האחרות בבחירה; אם אין הכרעה — מוצגים כולם.
- **חיפוש באוצריא:** פתיחת חיפוש, ופסוקים ומקורות קשורים עם קישורים.
- **קישור לכרטסות "עינים למקרא":** בעלי חיים, צומח, אישים, מקומות ועוד (דורש להתקין את התוסף "עינים למקרא").
- **דיווח** על הגדרה לא מתאימה, דרך אוצריא ובאישור המשתמש.

## התקנה
הורידו את קובץ ה-`.otzplugin` מדף ה-Releases, ובאוצריא: **כלים ← תוספים ← התקן תוסף חדש**.

## מבנה
```
manifest.json  index.html  background.html
js/   core.js (מנוע) · app.js (ממשק) · bg.js (זיהוי ברקע)
css/  data/ (dict.js — המילון, mh-index.js — שמות הערכים של עינים למקרא)
tools/build_dict.py       ← בונה את המילון מקובץ ה-ZIM
tools/build_mh_index.js   ← בונה את אינדקס עינים למקרא
tools/build_roadmap.py    ← ממיר את docs/ROADMAP.md להטמעה בתוסף
docs/ROADMAP.md           ← מסמך תכנון ותוכנית עבודה
```

## בנייה מחדש
```
pip install libzim
python tools/build_dict.py milon-klei-kodesh.zim dict.json     # ואז עוטפים: window.KK_DICT=<dict.json>;
node tools/build_mh_index.js ../madaei-hatanach data/mh-index.js
zip -r milon-klei-kodesh-X.Y.Z.otzplugin manifest.json index.html background.html css js data icon docs
```

## בדיקות
`node tests/run-roots.js -v` — מודד דיוק של זיהוי שורשים ובניינים מול `tests/roots.json`.

## תוכנית עבודה
ראו [`docs/ROADMAP.md`](docs/ROADMAP.md). אחרי עדכון המסמך: `python tools/build_roadmap.py docs/ROADMAP.md data/roadmap.js`.

## הערות
- **המאגר טרם סונן עד תומו.** ייתכנו ערכים לא מילוניים (שמות פרטיים), הגדרות כפולות או לא מדויקות, וערכים חסרים.
- הנתונים המילוניים לקוחים ממאגר המילון של פרויקט כליקודש (`milon-klei-kodesh.zim`). יש לוודא את תנאי הרישיון שלו לפני הפצה.
- שמות הערכים של "עינים למקרא" משמשים לקישור בלבד; התוכן נשאר בתוסף שלהם.
